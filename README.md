Weather App 🌦️

A simple and beautiful Weather App built using HTML, CSS, and JavaScript.
This app fetches real-time weather data for any city using the OpenWeatherMap API.

📌 Features
Search weather by city name
Displays:
🌡️ Temperature
☁️ Weather Condition
📍 City Name
Responsive and modern UI
Real-time weather data using API
Simple beginner-friendly JavaScript project
🛠️ Technologies Used
HTML5
CSS3
JavaScript (DOM + Fetch API)
OpenWeatherMap API
